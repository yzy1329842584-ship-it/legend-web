# 热血传奇 · 网页版

单机网页版《热血传奇》，纯 HTML/CSS/JS 单文件实现，浏览器直接打开即可游玩，无需任何后端或安装。

## 在线试玩

启用 GitHub Pages 后访问：`https://yzy1329842584-ship-it.github.io/legend-web/`

（也可直接下载 `index.html` 在浏览器中打开本地游玩，游戏自动在浏览器本地存档。）

## 玩法

- 三大职业：**战士**（近战爆发）、**法师**（远程范围魔法）、**道士**（召唤骷髅 + 治疗/毒术）
- 多张地图：比奇省 → 盟重省 → 祖玛寺庙，边缘传送阵换图
- 打怪爆装：金币、药品、武器/衣服/头盔/项链/戒指/手镯，含普通~传说品质
- 技能系统：每职业 4 个技能，数字键 1-6 释放
- 升级成长：击杀获得经验，升级提升攻击/防御/生命/魔法
- 排行榜：本机浏览器记录等级、击杀数、金币
- 全程自动存档（localStorage）

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 攻击目标 | 鼠标左键点击怪物 |
| 技能 | 数字键 1-6 |
| 红药/蓝药/太阳水 | 数字键 7 / 8 / 9 |
| 切换面板 | 右侧 角色/背包/装备/排行（手机端点 ☰） |

## 技术

单文件 Canvas 2D ARPG，无任何外部依赖，`index.html` 一个文件即完整游戏。
